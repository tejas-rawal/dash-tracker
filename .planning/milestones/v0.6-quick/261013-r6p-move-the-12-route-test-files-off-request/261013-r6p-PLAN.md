<objective>
Move the 12 route test files off throwaway per-request servers onto one long-lived server per file, the same shape `src/server/api/routes/rateLimit.test.ts` uses. Then mark the Phase 12 and Phase 14 deferred items resolved.

Purpose: supertest given the bare Express app runs `app.listen(0)` for every request and closes the server when the request ends (supertest 7.2.2 `lib/test.js:63` and `:134`; `request.agent(app)` does the same per request, so it is not a fix). Node 20's keep-alive `http.globalAgent` can then reuse a pooled socket to a closed server whose port the OS has given to a new one, so a request can be answered by a server the test never meant to hit. The Phase 14 deferred item records this. One server per file removes the throwaway servers. The Phase 12 item (the Biome diff in `.superset/config.json`) was already fixed by commit `9be1043`. Only its doc entry is still open.
