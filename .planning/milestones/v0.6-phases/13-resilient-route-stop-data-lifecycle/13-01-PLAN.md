<objective>
Make "route/stop data has not loaded yet" a typed error that every controller turns into a 503 through one shared error helper, proven end to end on the deepest existing path (the SSE stream, D-04) and then on vehicle route filters.

1. `DataNotReadyError` joins `NotFoundError`/`UpstreamApiError` in `src/server/api/errors/index.ts`, and the repository's not-loaded guard throws it (D-01).
2. New `sendErrorResponse(res, error)` in `src/server/api/controllers/errorResponse.ts` is the single mapping: 404 / 503 + `Retry-After: 5` / 502 / generic, logged 500 (D-02, D-03).
3. `PredictionStreamController` (tracer) and `VehicleController` use it. Plans 13-02 and 13-04 migrate the other six controllers.

Purpose: BOOT-03 and success criterion 2 (503 instead of 500 before the first load). This also closes the STATE.md WR-02/IN-04 follow-up: no 500 response echoes raw `error.message` any more.
Output: `DataNotReadyError`, `errorResponse.ts` + its tests, two migrated controllers, and the real-app E2E file `src/server/api/routes/dataNotReady.test.ts` that plans 13-02 and 13-04 extend.

Resolved PATTERNS discrepancies:
- D-03 says the 503 uses the existing `{ error, message }` shape, but every existing error body is `{ error, details }`. D-03's intent is "the existing shape", so the 503 body is `{ error: "Service Unavailable", details: <DataNotReadyError message> }`.
- No controller sets a header today. `Retry-After` is the first `res.set(...)`; unit tests that hit the 503 path add a `set` mock.
- The tracer is the SSE controller on purpose: its unit tests have no 500 assertions, so the generic 500 can ship in the tracer without rewriting any test. Controllers whose tests lock in the 500 echo are migrated together with those tests (Task 3 here, plans 13-02 and 13-04).

Prohibition probe (spec-less fallback): one bespoke prohibition kept here (no 200-with-empty-data before load, a rider-transparency value). Leaking raw error text or `DASH_API_KEY` in responses/logs is canon (OWASP sensitive-data exposure), so it is covered by `/gsd-secure-phase` and threats T-13-01/T-13-03 rather than minted as a prohibition.

Reversibility: D-02 is rated costly in CONTEXT (touches every controller's error path and its tests). Flagged on Task 1; no checkpoint because the user already chose this option in discuss-phase.
</objective>
