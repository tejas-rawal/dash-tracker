|----------|-------------|
| DASH upstream to API server | An untrusted peer that can hang. Boot and the background poll call it outside any HTTP request, so a hang there would otherwise be silent. |
| API server to rider client | 502 `details` echo `UpstreamApiError.message`. The nearby request URL carries the rider's coordinates. |

| T-12-08 | Denial of service | Startup route/stop load and 5-minute alert poll (background DASH calls) | high | mitigate | Both go through the same bounded client (D-01). The E2E proves each rejects at the deadline and logs an error instead of hanging boot or the poll. |
