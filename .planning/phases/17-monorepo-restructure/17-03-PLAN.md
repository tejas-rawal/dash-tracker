    - With `cd … && bun run dev-server`, the shell forks bun, so the signal hits only the shell. nodemon and ts-node survived and the port stayed bound, for both signals.
    - With `cd … && exec bun run dev-server`, bun replaces the shell. Both signals left no process and freed the port within 1-2 s.
    - `zsh -c` already execs the last command of an `&&` list. `exec` makes the result the same under any shell.
