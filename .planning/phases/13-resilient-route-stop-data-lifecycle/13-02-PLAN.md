<objective>
Move the rider's core read paths (route list, route detail, route stops, nearby stops, REST predictions) onto the shared error helper from plan 13-01. Before the first load they answer 503 + Retry-After instead of 500, and a generic 500 no longer echoes the thrown message.

Purpose: BOOT-03 / success criterion 2 for the most-used endpoints, and D-02 for three of the eight controllers. Plan 13-01 covered PredictionStream and Vehicle; plan 13-04 covers Favorites, Recents and Nearby.
Output: three migrated controllers; their unit and route-level 500 tests rewritten to the generic body; five more E2E rows in `src/server/api/routes/dataNotReady.test.ts`.

The tracer is the route list. It is the thinnest rider-visible path: route → BusRouteController → BusRouteService → repository → sendErrorResponse.

Reversibility: D-02 is rated costly in CONTEXT. It is flagged on Task 1 with no checkpoint, because the user already chose this option in discuss-phase.
</objective>
