Route responses carry DASH's own route colors. The live routes payload captured on 2026-11-10 has `color` and `textColor` on all 12 routes, so CORS-05 applies (D-16). `RouteData` reads both fields, `BusRoute` carries them, and every route response serializes them exactly as DASH sends them. A missing or malformed value omits that one field and never fails the atomic load (D-17).

Purpose: CORS-05, so the Phase 19 route list can draw badges in the agency's colors, using DASH's `textColor` (research conflict 5). Per D-01 this runs after the toolchain, in parallel with the CORS mount (plan 18-04); the two plans share no files.
Output: optional `color`/`textColor` on `BusRoute`, a never-throwing hex filter in the repository, an end-to-end route test, and coercion tests.
</objective>
